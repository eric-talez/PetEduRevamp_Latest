“펫스포트(PetSport / Pet Passport)” 방향은 굉장히 좋습니다.
특히 지금 한국 시장은 단순 반려견 커뮤니티보다:

* 인증
* 출입
* 예방접종
* 훈련 이력
* 시설 이용
* 보험
* 여행

이 연결되는 “반려견 신원 인프라” 쪽이 아직 비어 있습니다.

그리고 테일즈 오프라인 공간 + 훈련 + QR 인증 구조와도 매우 잘 맞습니다.

다만 중요한 건:

# “펫스포트”를 단순 QR 명함으로 만들면 안 됩니다.

성공하는 구조는:

```txt
강아지의 디지털 신원 체계
```

가 되어야 합니다.

즉 사람의:

* 여권
* 신분증
* 백신패스
* 운전면허
* 건강기록

을 합친 개념으로 가야 합니다.

---

# 추천 포지셔닝

## 잘못된 방향

```txt
강아지 QR 생성 서비스
```

→ 너무 약함
→ 금방 복제됨

---

# 좋은 방향

```txt
반려견 디지털 패스포트 인프라
```

또는

```txt
반려견 인증 네트워크
```

# 핵심 개념

## 강아지 1마리 = 1개의 디지털 ID

예:

```json
{
  "pet_uid": "PTS-9A82X",
  "animal_reg_no": "410123456789012",
  "name": "보더",
  "breed": "Border Collie",
  "vaccination_status": true,
  "rabies_expire": "2027-04-01",
  "training_level": "ADVANCED",
  "verified_hospital": true
}
```

# 진짜 중요한 건 “신뢰도 레이어”

단순 프로필이 아니라:

| 항목       | 중요도   |
| -------- | ----- |
| 국가 등록 인증 | 매우 중요 |
| 병원 인증    | 핵심    |
| 광견병 인증   | 핵심    |
| 훈련 인증    | 차별화   |
| 행동 평가    | 차별화   |
| 출입 허가    | 미래 핵심 |
| 보험 연동    | 미래 핵심 |

입니다.

# 추천 서비스 구조

# 1. Pet Passport (핵심)

QR 기반 반려견 신원

기능:

* 등록번호
* 보호자
* 예방접종
* 중성화
* 병원 기록
* 알러지
* 긴급 연락처

---

# 2. Pet Entry Pass

시설 출입 인증

예:

* 카페
* 호텔
* 애견운동장
* 유치원
* 비행기
* 캠핑장

QR 스캔 → 입장 가능 여부

---

# 3. Training Identity

테일즈와 엄청 잘 맞는 부분입니다.

예:

```txt
사회성 Lv3
공격성 평가 통과
대형견 리드워크 인증
카페 매너 인증
```

이런 인증 체계.

이건 다른 플랫폼이 따라오기 어렵습니다.

---

# 4. Medical Passport

예방접종 및 건강 이력

예:

* 광견병
* 종합백신
* 심장사상충
* 알러지
* 처방식

---

# 5. Lost Mode

분실 모드

QR 스캔 시:

* 보호자 연락
* 위치 공유
* 병원 연결

---

# 현재 한국 시장 문제

지금은 정보가 다 분산되어 있습니다.

| 영역     | 문제    |
| ------ | ----- |
| 병원     | 폐쇄적   |
| 등록번호   | 기억 못함 |
| 예방접종   | 종이    |
| 훈련     | 표준 없음 |
| 출입 인증  | 수기 확인 |
| 반려견 신원 | 없음    |

즉:
“통합 신원 시스템”

자체가 아직 없습니다.

# 3. 위조 방지

이거 중요합니다.

왜냐면:

* 예방접종 위조
* 광견병 위조

문제가 실제 존재합니다.

그래서:

* 병원 서명
* 타임스탬프
* 디지털 인증

이 필요합니다.

# 진짜 중요한 BM

많은 사람들이:
“QR 발급 수수료”

를 생각하는데 아닙니다.

핵심 BM은:

| BM       | 가능성  |
| -------- | ---- |
| 병원 SaaS  | 매우 큼 |
| 출입 인증    | 매우 큼 |
| 보험 연동    | 큼    |
| 프리미엄 인증  | 큼    |
| 시설 API   | 매우 큼 |
| 호텔/항공 인증 | 미래 큼 |

입니다.

---

# 테일즈와 연결하면 엄청 강력한 이유

테일즈는 이미:

* 훈련
* 행동평가
* 오프라인 공간
* 커뮤니티
* 출입

이 있습니다.

즉:

```txt
펫스포트 = 신원 시스템
테일즈 = 인증 기관
```

구조가 가능합니다.

이건 꽤 강력한 진입장벽이 됩니다.
