Business goal:
Talez wants to show Korea-based pet/dog-related regional events in one place. Users should be able to open a map, browse markers across South Korea, filter events by region/category/date, and click each event to see details and the original source.

Important clarification:
Google Maps API is used for:
- Rendering the map
- Showing markers
- Marker clustering
- Info windows
- Geocoding addresses into coordinates
- Optionally enriching venue/location information

Google Maps API is NOT the primary event data source. Event data should come from:
- Existing event/news system if available
- Google News RSS search queries
- Manually configurable source URLs
- Future official local government/city event pages
- Future pet fair/adoption/shelter/event provider sources

Use Google Maps Platform properly:
- Maps JavaScript API for frontend map rendering
- Geocoding API for server-side address-to-coordinate conversion
- Places API Text Search only as optional venue enrichment, not as the main event source
- Use minimal fields/field masks when calling Places API to control cost
- Cache geocoding and place results in the database

Geocoding:
Create a server-side geocoding service.

Rules:
1. If address exists, geocode address.
2. If address does not exist but venue + city/province exists, geocode “venueName city province South Korea”.
3. If only city/province exists, geocode broader city/province with lower confidence.
4. Cache all geocoding results.
5. Do not call Google repeatedly for the same normalized query.
6. Store confidence:
   - 0.95 exact address
   - 0.80 venue match
   - 0.60 city/province only
   - below 0.60 should be needs_review
7. If geocoding fails, still save the event with status needs_review.
